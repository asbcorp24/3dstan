# 3DStan

Веб-программа для 3D-планировки цеха, размещения станков и последующего отслеживания состояния оборудования.

## Возможности

- 3D-сцена на Three.js с метрической сеткой 0,5 м.
- Изометрический и верхний вид.
- Правая база оборудования с категориями и поиском.
- Добавление оборудования кликом или drag & drop.
- Импорт реальных 3D-моделей станков из STL (ASCII/Binary).
- Хранение STL на сервере и повторное использование модели в разных планировках.
- Поддержка исходных единиц STL: мм, см, м.
- Принудительное задание фактических габаритов X/Z/Y в метрах для защиты от неправильного CAD-масштаба.
- Перемещение оборудования с привязкой к сетке.
- Поворот клавишей `R` или через панель свойств.
- Редактирование размеров и произвольных параметров.
- Паспорт оборудования: модель, изготовитель, заводской/инвентарный номер, год выпуска, масса, мощность, питание, участок, ответственный, ТО и др.
- Состояния оборудования: `Работает`, `Отключён`, `Простой`, `Обслуживание`, `Ремонт`, `Авария`.
- Автоматическое визуальное выделение оборудования по состоянию.
- Рисование стен.
- Добавление дверей.
- Дерево объектов сцены.
- Сохранение и загрузка нескольких планировок.
- SQLite-база данных.
- REST API на Flask.

## Запуск

Windows PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Открыть:

```text
http://127.0.0.1:5000
```

При обновлении уже существующей установки удалять `factory.db` не требуется: `app.py` сам добавит недостающие поля STL в старую SQLite-базу.

## Как импортировать станок из STL

1. Справа в блоке **База оборудования** нажать **+ Добавить**.
2. Ввести имя, например `16К20 №1`.
3. Указать категорию, например `Металлообработка / Токарные`.
4. Задать реальные габариты станка в метрах: ширина X, глубина Z, высота Y.
5. Выбрать `.stl` файл.
6. Указать, в каких единицах был экспортирован исходный STL: мм, см или м.
7. Нажать **Добавить в базу**.
8. В списке появится отметка `STL`.
9. Нажать на станок или перетащить его мышью на план.
10. Three.js загрузит модель с сервера и подгонит её под заданные реальные габариты.

STL-файлы до 100 МБ принимаются endpoint `POST /api/equipment-types/import-stl`.

## Управление

- ЛКМ по объекту — выбрать.
- Перетаскивание — переместить объект по сетке.
- ПКМ + движение — вращение камеры.
- Колесо — масштаб.
- `R` — повернуть выбранный объект на 90°.
- `Delete` — удалить выбранный объект.
- `Esc` — выйти из режима рисования.

## API

- `GET /api/equipment-types` — база типов оборудования.
- `POST /api/equipment-types` — добавить тип без STL.
- `POST /api/equipment-types/import-stl` — создать тип оборудования и загрузить STL.
- `GET /api/layouts` — список планировок.
- `GET /api/layouts/<id>` — открыть планировку.
- `POST /api/layouts` — сохранить/обновить планировку.
- `DELETE /api/layouts/<id>` — удалить планировку.
- `GET /api/health` — проверка backend.
