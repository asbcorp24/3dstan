# 3DStan

Веб-программа для 3D-планировки цеха и размещения станков/оборудования на заводе.

## Возможности текущей версии

- 3D-сцена на Three.js с метрической сеткой 0,5 м.
- Изометрический и верхний вид.
- Правая база оборудования с категориями и поиском.
- Добавление оборудования кликом или drag & drop на план.
- Перемещение оборудования по сетке.
- Поворот оборудования клавишей `R` или через панель свойств.
- Редактирование имени, размеров и произвольных параметров станка.
- Рисование стен по двум точкам.
- Добавление дверей.
- Дерево объектов текущей сцены.
- Удаление объектов клавишей `Delete` или кнопкой.
- Сохранение и загрузка нескольких планировок.
- SQLite-база данных.
- REST API на Flask.

## Запуск

Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Windows PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

Открыть:

```text
http://127.0.0.1:5000
```

## Управление

- ЛКМ по объекту — выбрать.
- Перетянуть выбранное оборудование — переместить с привязкой к сетке.
- ПКМ + движение — вращение камеры.
- Колесо — приближение/отдаление.
- `R` — повернуть выбранный объект на 90°.
- `Delete` — удалить выбранный объект.
- `Esc` — выйти из режима рисования стены/двери.

## API

- `GET /api/equipment-types` — база типов оборудования.
- `POST /api/equipment-types` — добавить новый тип оборудования.
- `GET /api/layouts` — список планировок.
- `GET /api/layouts/<id>` — открыть планировку.
- `POST /api/layouts` — сохранить/обновить планировку.
- `DELETE /api/layouts/<id>` — удалить планировку.
- `GET /api/health` — проверка backend.
